# Эксплуатация ИС — тренажёр

Готовый мобильный сайт по файлу `111.xlsx`.

## Что внутри

- 505 вопросов, 14 блоков.
- Каждый вопрос сохранён с исходным идентификатором вида `01.05`.
- Все правильные варианты взяты из зелёных ячеек исходной таблицы.
- Текст ответов не изменён.
- При каждой попытке перемешиваются и вопросы, и варианты ответов.
- Экзамен: ровно 14 вопросов — по одному случайному из каждого блока.
- Тренажёр по отдельным категориям.
- Марафон: все 505 вопросов в случайном порядке.
- Локальная статистика в `localStorage`.
- Тёмная/светлая тема, рассчитано на телефон.
- Полностью статический фронтенд: достаточно Nginx/Apache или Docker.

## Запуск через Docker

```bash
docker compose up -d --build
```

Открыть: http://localhost:8080

## Запуск без Docker

Можно просто отдать папку через любой веб-сервер. Например:

```bash
python3 -m http.server 8080
```

Источник: `111.xlsx`.
